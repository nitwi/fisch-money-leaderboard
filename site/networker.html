    How these comparisons work

    RBI avatar review: each preset is a specific set of asset IDs from the linked published RBI release. Full means every preset ID is equipped; partial means at least one, but not every, ID is equipped. A one-item preset can produce a full 1/1 match. Review order puts full matches first, then partial matches by the number of distinct preset IDs observed. Results describe the avatar observation time, independently of the historical leaderboard photo.

    Avatar overlap: shared asset IDs ÷ the union of both equipped asset sets. Clothing and accessories are compared separately from body parts and animations so common defaults do not dominate the cosmetic comparison. An empty or unavailable avatar is never a 100% match.

    Username patterns: explained rules compare distinctive name stems, numbered variants, separators, meaningful tokens, and common character substitutions. Generic words, short fragments, digit-only overlap, and weak similarities in random-looking strings are suppressed. Strong and possible labels describe the detected text pattern. They are review hints, with no ownership probability. Display names are excluded. The comparison runs locally in your browser and does not call an AI service.

    Social links: only exact account IDs in a readable API list or a documented website observation create links. Start from the selected main account and expand connected nodes using saved observations. Branches include photographed leaderboard accounts from all history, or external accounts with a full match to one of the 22 RBI presets. Near matches appear only in the separate relationship breakdown; unchecked avatars remain unknown. Username or outfit resemblance alone never creates an edge. Follow direction and source times are preserved. The searchable list below the graph retains all observed direct friends. Partial-list shared friends are a minimum observed count.

    Matching assets and similar names describe public account features. They do not establish common ownership or misconduct.
